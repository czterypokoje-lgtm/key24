# Release checklist (must be evidence-backed)

## Visual and navigational
- [ ] Existing desktop/mobile before screenshots captured
- [ ] Existing design tokens, navbar and hero structure preserved
- [ ] Every route in page-manifest resolves without 404
- [ ] Mobile nav, dropdowns, language switcher and keyboard access work
- [ ] No horizontal overflow at 320/390; German copy wraps correctly
- [ ] All pricing cards, accordions, featured media and product sections coherent

## Product and proof
- [ ] No fabricated testimonials, metrics, reviews, user counts, certifications or clients
- [ ] Customer release records exist for shown names, logos, quotes, photos
- [ ] Exact package features and allowances formally approved
- [ ] Growth highlighted without fake endorsement and no fake scarcity
- [ ] Video/audio player genuinely works and has meaningful accessibility support
- [ ] Optional AI ad management describes eligible advertising, not answer influence

## Conversion and security
- [ ] Book-demo integration routes to actual appointment or form accurately confirms lead only
- [ ] CRM leads verified in staging and protected with server-side env secrets
- [ ] Server validation, spam/rate protections, privacy links, duplicate handling working
- [ ] Analytics event names document only meaningful user actions, no PII
- [ ] Unavailable sections hidden or honestly labeled, never dead CTA

## Legal and performance
- [ ] Company identity, contact, local privacy/cookies/terms reviewed
- [ ] Cookie/analytics choices tested and don't auto-fire nonessential trackers before consent
- [ ] Outreach list separately checked for country- and recipient-specific lawful permission
- [ ] App typechecks, lints, builds and passes E2E smoke tests
- [ ] SEO canonical, sitemaps, hreflang and robots work
- [ ] Deployment rollback tested and production environment configured
